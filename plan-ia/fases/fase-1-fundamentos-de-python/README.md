# Fase 1 – Fundamentos de Python (acelerado)

Al terminar esta fase podés escribir scripts que leen datos, los procesan y manejan errores, todo desde la terminal y con Git.

- **Plan:** [Fase 1 en el README](../../README.md#fase-1--fundamentos-de-python-acelerado)
- **Requisitos:** ninguno.
- **Horas estimadas:** 100

## Empezá acá

La instalación es la misma que la del mapa principal: seguí la guía "Empezá acá" del [nivel 0 – Preparación](../../../niveles/nivel-00-preparacion/README.md) (terminal, `uv`, Python 3.15, entorno virtual, Git y tu primer commit). Hay una sola diferencia: guardá tus archivos en las carpetas de esta fase (`plan-ia/fases/fase-1-fundamentos-de-python/`) en lugar de las del nivel 0.

## Mini proyecto

Un script de terminal que lee un archivo CSV o JSON real (gastos, lecturas, notas), calcula un resumen y lo guarda en JSON, con manejo de errores para archivos que faltan o datos mal formados. Guardalo en `proyecto/` con al menos cinco commits con mensajes claros.

## Cómo usar la IA en esta fase

- Todos los ejercicios de CS50P y de Helsinki se resuelven sin IA. Si te trabás, pedile una pista o la explicación del concepto, nunca el código.
- Cuando el ejercicio pasa, pedile una revisión y preguntale qué haría un programador con experiencia distinto.
- Pedile que te explique los mensajes de error que no entendés, pero leé primero el traceback completo vos.
- No uses autocompletado con IA en el editor durante esta fase: te quita justo la práctica que esta fase da.

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto de la fase.
