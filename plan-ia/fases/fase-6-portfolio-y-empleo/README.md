## Ejercicios

- [ ] 1. Proyecto 1: un RAG sobre documentos reales, con citas, una suite de evals y un informe de calidad en el README (45 h).
- [ ] 2. Proyecto 2: un agente con herramientas propias expuestas por un servidor MCP, con límites de pasos y de gasto y defensas contra prompt injection (40 h).

## Mini proyecto

En esta fase el proyecto son los tres del portfolio. Cada uno va en su propio repositorio público, con un README que diga qué problema resuelve, cómo correrlo, qué decisiones tomaste (modelo, RAG o no, cómo evaluás, cuánto cuesta por pedido) y qué mejorarías. En `proyecto/` de esta fase dejá un README con los enlaces a los tres.

## Cómo usar la IA en esta fase

- Usá la IA como entrevistadora: pedile que te haga preguntas sobre tus proyectos y que repregunte cuando una respuesta sea vaga.
- Pedile que revise tus README como lo haría alguien que contrata, y corregí lo que no se entiende.
- En los simulacros de algoritmos, nada de IA hasta terminar el problema; después, pedile otra solución y compará.
- Preparate para la pregunta "¿qué parte de este proyecto escribió una IA?": la respuesta buena es que podés explicar y defender todo.
