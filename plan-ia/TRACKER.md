# Tracker del plan para AI Engineer

Para empezar: [fases/fase-1-fundamentos-de-python](fases/fase-1-fundamentos-de-python/). Cada fase tiene su carpeta en [`fases/`](fases/).

Marcá cada casilla solo cuando puedas resolver los ejercicios del tema (columna "Ejercicios" del [README](README.md)) sin mirar la teoría y sin pedirle la solución a una IA. Para marcarla, cambiá `- [ ]` por `- [x]`. Las horas entre paréntesis son las estimadas en el README (sección [Tiempo estimado](README.md#tiempo-estimado)).

## Fase 1 – Fundamentos de Python (acelerado)

Carpeta: [fase-1-fundamentos-de-python](fases/fase-1-fundamentos-de-python/)

- [ ] Preparación: terminal, Python 3.15 con `uv`, entorno virtual, Git básico (15 h)
- [ ] Primeros pasos y control de flujo: CS50P semanas 0–2 (30 h)
- [ ] Colecciones: listas, tuplas, diccionarios, conjuntos, strings (20 h)
- [ ] Errores, archivos y JSON: excepciones, CSV, JSON, expresiones regulares (20 h)
- [ ] Terminal: permisos, pipes, variables de entorno, `PATH` (15 h)

## Fase 2 – Programador práctico

Carpeta: [fase-2-programador-practico](fases/fase-2-programador-practico/)

- [ ] Programación orientada a objetos: clases, herencia, dataclasses (15 h)
- [ ] Testing: pytest, fixtures, mocks (15 h)
- [ ] Tipos y validación: type hints, mypy, Pydantic (10 h)
- [ ] Proyecto Python moderno: `pyproject.toml`, `uv`, `ruff`, secretos (10 h)
- [ ] Git en equipo: ramas, merge, rebase, pull requests (10 h)
- [ ] HTTP y clientes: HTTPX, `asyncio`, reintentos (15 h)
- [ ] APIs con FastAPI (20 h)
- [ ] PostgreSQL desde Python: SQL y psycopg 3 (30 h)
- [ ] Docker y Docker Compose (15 h)
- [ ] Proyecto integrador: API con FastAPI, PostgreSQL y Docker, con tests (20 h)

## Fase 3 – Datos y ML esencial

Carpeta: [fase-3-datos-y-ml-esencial](fases/fase-3-datos-y-ml-esencial/)

- [ ] Matemática mínima: vectores, producto punto, similitud coseno, probabilidad básica (25 h)
- [ ] NumPy: arrays, vectorización, broadcasting (10 h)
- [ ] pandas: DataFrames, filtros, agregaciones (15 h)
- [ ] Conceptos de ML: Machine Learning Crash Course (20 h)
- [ ] Evaluación con scikit-learn: validación cruzada y métricas (20 h)

## Fase 4 – Cómo funcionan los LLMs

Carpeta: [fase-4-como-funcionan-los-llms](fases/fase-4-como-funcionan-los-llms/)

- [ ] Redes neuronales: MIT 6.S191, clases 1 y 2 (15 h)
- [ ] Embeddings y LLMs: módulos de Machine Learning Crash Course (10 h)
- [ ] Transformers y tokenización: LLM Course de Hugging Face (20 h)
- [ ] Preentrenamiento, fine-tuning y RLHF: Stanford CS224N (20 h)
- [ ] Tokens, contexto y sampling (10 h)

## Fase 5 – AI Engineering

Carpeta: [fase-5-ai-engineering](fases/fase-5-ai-engineering/)

- [ ] Primera API: SDK, mensajes, system prompt, errores (20 h)
- [ ] Prompt engineering (15 h)
- [ ] Salidas estructuradas (10 h)
- [ ] Herramientas (tool use) (20 h)
- [ ] Streaming, costo y latencia: prompt caching, conteo de tokens (15 h)
- [ ] Embeddings y búsqueda vectorial con pgvector (20 h)
- [ ] RAG (30 h)
- [ ] Agentes (40 h)
- [ ] Model Context Protocol (MCP) (25 h)
- [ ] Evals (25 h)
- [ ] Seguridad: OWASP Top 10 for LLM Applications (10 h)
- [ ] Observabilidad: OpenTelemetry para IA generativa (10 h)

## Fase 6 – Portfolio y empleo

Carpeta: [fase-6-portfolio-y-empleo](fases/fase-6-portfolio-y-empleo/)

- [ ] Proyecto 1: RAG con evals (45 h)
- [ ] Proyecto 2: agente con herramientas expuestas por un servidor MCP (40 h)
