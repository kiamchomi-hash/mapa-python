# Nivel 10 – Diseño de software

Al terminar este nivel podés especificar, probar y diseñar tipos abstractos de datos en Python con type hints, como se enseña en MIT 6.102.

- **Etapa:** [Etapa 2 – Programador sólido](../../README.md#etapa-2--programador-sólido-niveles-610)
- **Requisitos:** nivel 9.
- **Horas estimadas:** 60

## Fuentes

- [MIT 6.102 Software Construction](https://web.mit.edu/6.102/www/sp26/) (Spring 2026), solo las clases 01–09: de [Static Checking](https://web.mit.edu/6.102/www/sp26/classes/01-static-checking/) a [Equality](https://web.mit.edu/6.102/www/sp26/classes/09-equality/). El curso usa TypeScript; los conceptos aplican a Python.

## Ejercicios

- [ ] 1. Los reading exercises de las clases 01–09.
- [ ] 2. Aplicar cada idea en Python con type hints: especificaciones como docstrings, chequeo del invariante de representación y tests.

## Mini proyecto

Un tipo abstracto de datos en Python (por ejemplo, un conjunto de intervalos de tiempo) con especificación en cada método, función de abstracción e invariante de representación documentados, un método `_check_rep()`, igualdad definida y tests que cubren las particiones de cada entrada.

Con este nivel termina la Etapa 2. El resto de MIT 6.102 (clases 10–19 y los problem sets, en TypeScript) es "Diseño de software a fondo", en la Etapa 3. Ese trabajo también va en `proyecto/` de este nivel.

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] El mini proyecto está en `proyecto/` y funciona.
- [ ] Cada método público tiene especificación y los tests verifican el invariante.
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
