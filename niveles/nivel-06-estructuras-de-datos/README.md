# Nivel 6 – Estructuras de datos y pensamiento algorítmico

Al terminar este nivel podés implementar y elegir estructuras de datos, y estimar la complejidad (Big O) de tu código.

- **Etapa:** [Etapa 2 – Programador sólido](../../README.md#etapa-2--programador-sólido-niveles-610)
- **Requisitos:** Etapa 1 completa.
- **Horas estimadas:** 60

## Fuentes

- [MIT 6.100L](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/) (Fall 2022, OCW)
- [Tutorial oficial: estructuras de datos](https://docs.python.org/es/3/tutorial/datastructures.html)
- Documentación de [`collections`](https://docs.python.org/3/library/collections.html) y [`heapq`](https://docs.python.org/3/library/heapq.html)
- CS61A (listas enlazadas y árboles)

## Ejercicios

- [ ] 1. [Problem sets de MIT 6.100L](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/lists/problem-sets/) y finger exercises.
- [ ] 2. Homework de CS61A sobre listas enlazadas y árboles.
- [ ] 3. Implementar desde cero, con tests, una pila, una cola, una lista enlazada, un árbol binario de búsqueda, una tabla hash y un heap.

## Mini proyecto

Un comparador de rendimiento: medir con `timeit` la búsqueda en una lista, en un `set` y en tu tabla hash, y tu ordenamiento contra `sorted`, con una tabla de resultados en el README del proyecto.

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
