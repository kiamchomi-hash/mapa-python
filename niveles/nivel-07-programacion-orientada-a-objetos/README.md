# Nivel 7 – Programación orientada a objetos

Al terminar este nivel podés diseñar programas con clases, herencia, composición y métodos especiales.

- **Etapa:** [Etapa 2 – Programador sólido](../../README.md#etapa-2--programador-sólido-niveles-610)
- **Requisitos:** nivel 6.
- **Horas estimadas:** 35

## Fuentes

- [MIT 6.100L](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/) (segunda mitad)
- [Harvard CS50P](https://cs50.harvard.edu/python/) (semana 8)

## Ejercicios

- [ ] 1. Problem sets de la segunda mitad de MIT 6.100L.
- [ ] 2. CS50P: Problem Set 8.

## Mini proyecto

Un sistema de inventario o de biblioteca con clases, composición y herencia, y métodos especiales (`__str__`, `__eq__`, `__len__`).

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] El mini proyecto está en `proyecto/` y funciona.
- [ ] Explicás dónde usaste herencia, dónde composición y por qué.
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
