# Nivel 9 – Calidad

Al terminar este nivel podés escribir código legible, probado y versionado con ramas y pull requests, como en un equipo.

- **Etapa:** [Etapa 2 – Programador sólido](../../README.md#etapa-2--programador-sólido-niveles-610)
- **Requisitos:** nivel 8. Con este nivel empieza el escalón avanzado del track de terminal y Linux.
- **Horas estimadas:** 40

## Fuentes

- [PEP 8](https://peps.python.org/pep-0008/)
- [Documentación de Ruff](https://docs.astral.sh/ruff/) (Astral)
- [Documentación de pytest](https://docs.pytest.org/)
- [MIT Missing Semester](https://missing.csail.mit.edu/2026/) (edición 2026)
- [Pro Git](https://git-scm.com/book/es/v2) (libro oficial de Git, en español)

## Ejercicios

- [ ] 1. CS50P: Problem Set 5 (unit tests).
- [ ] 2. Ejercicios de las clases Version Control and Git, Debugging and Profiling y [Code Quality](https://missing.csail.mit.edu/2026/code-quality/) de Missing Semester.
- [ ] 3. Configurar `ruff` y pytest en un proyecto propio.

## Mini proyecto

Llevar el paquete del nivel 8 a calidad profesional: `ruff` sin avisos, tests con pytest, docstrings y cada cambio en una rama con su pull request.

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] El mini proyecto está en `proyecto/` y funciona.
- [ ] `ruff check` y `pytest` pasan sin errores en tu proyecto.
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
