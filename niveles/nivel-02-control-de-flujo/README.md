# Nivel 2 – Control de flujo

Al terminar este nivel podés escribir programas que deciden y repiten con condicionales, bucles y `match`.

- **Etapa:** [Etapa 1 – Fundamentos](../../README.md#etapa-1--fundamentos-niveles-05)
- **Requisitos:** nivel 1.
- **Horas estimadas:** 20

## Fuentes

- [Harvard CS50P](https://cs50.harvard.edu/python/)
- [MOOC de Helsinki 2026](https://programming-26.mooc.fi/) (partes 1–2)

## Ejercicios

- [ ] 1. CS50P: Problem Set 1.
- [ ] 2. CS50P: Problem Set 2.
- [ ] 3. Ejercicios de las partes 1–2 del MOOC de Helsinki.

## Mini proyecto

Un juego de adivinar un número con intentos limitados y un menú de opciones resuelto con `match`.

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] El mini proyecto está en `proyecto/` y funciona.
- [ ] Elegís entre `for` y `while` y podés explicar por qué.
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
