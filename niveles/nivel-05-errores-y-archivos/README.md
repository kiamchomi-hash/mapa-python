# Nivel 5 – Errores y archivos

Al terminar este nivel podés escribir scripts completos que leen CSV y JSON, procesan los datos, validan texto con expresiones regulares y manejan errores sin romperse.

- **Etapa:** [Etapa 1 – Fundamentos](../../README.md#etapa-1--fundamentos-niveles-05)
- **Requisitos:** nivel 4.
- **Horas estimadas:** 30

## Fuentes

- [Harvard CS50P](https://cs50.harvard.edu/python/) (semanas 3, 6 y 7)
- [Regular Expression HOWTO](https://docs.python.org/3/howto/regex.html)
- [Logging HOWTO](https://docs.python.org/3/howto/logging.html)

## Ejercicios

- [ ] 1. CS50P: Problem Set 3.
- [ ] 2. CS50P: Problem Set 6.
- [ ] 3. CS50P: Problem Set 7.

## Mini proyecto

Un script que lee un CSV de gastos, valida cada fila con `re`, escribe un resumen en JSON y registra las filas inválidas con `logging`.

Con este nivel termina la Etapa 1.

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] El mini proyecto está en `proyecto/` y funciona.
- [ ] El script no se cae con un archivo mal formado: informa el error y sigue o termina con un mensaje claro.
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
