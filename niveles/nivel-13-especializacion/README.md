# Nivel 13 – Especialización

Al terminar este nivel podés trabajar en cuatro dominios de Python: web, automatización, datos e IA.

- **Etapa:** [Etapa 3 – Python avanzado](../../README.md#etapa-3--python-avanzado-niveles-1113)
- **Requisitos:** cada especialización tiene los suyos (tabla de abajo).
- **Horas estimadas:** 620 en total (150 de web, ya contadas antes del nivel 14, y 470 de las otras tres)

## Las cuatro especializaciones

Se cursan una por vez y en este orden. El detalle está en [Especializaciones del nivel 13](../../README.md#especializaciones-del-nivel-13).

| Orden | Especialización | Cuándo | Fuentes | Horas |
| --- | --- | --- | --- | --- |
| 1 | Web | Después del nivel 10, antes del nivel 14 | [Harvard CS50W](https://cs50.harvard.edu/web/) + [MDN Web Docs](https://developer.mozilla.org/es/docs/Learn_web_development) | 150 |
| 2 | Automatización | Después de la Etapa 3 (niveles 11–12) | [Biblioteca estándar de Python](https://docs.python.org/3/library/index.html) + [Playwright para Python](https://playwright.dev/python/) + [documentación de Ansible](https://docs.ansible.com/) | 50 |
| 3 | Datos | Después de automatización; requiere probabilidad (Harvard Stat 110) | [Berkeley Data 100](https://ds100.org/) + [documentación de Matplotlib](https://matplotlib.org/stable/) + [documentación de Apache Airflow 3](https://airflow.apache.org/docs/) | 200 |
| 4 | IA | Al final; requiere la Etapa 3 y el track de matemáticas completo | [Stanford CS229](https://cs229.stanford.edu/) + [documentación de scikit-learn](https://scikit-learn.org/stable/) | 220 |

## Ejercicios

- [ ] 1. Web: los [proyectos de CS50W](https://cs50.harvard.edu/web/projects/), incluido el proyecto final.
- [ ] 2. Automatización: automatizar tres tareas reales tuyas: un script de archivos con `argparse`, una prueba de navegador con Playwright y un playbook de Ansible sobre una máquina virtual.
- [ ] 3. Datos: homework y labs de Data 100.
- [ ] 4. IA: problem sets de CS229.

## Mini proyecto

Uno por especialización, cada uno en su subcarpeta de `proyecto/` (`web/`, `automatizacion/`, `datos/`, `ia/`):

- Web: el proyecto final de CS50W.
- Automatización: las tres automatizaciones del ejercicio 2, con un README que explique cómo correrlas.
- Datos: un análisis de datos reales con un pipeline programado en Airflow que lo actualice.
- IA: un modelo clásico con scikit-learn, evaluado con validación cruzada y comparado contra una línea de base simple.

## Listo cuando

- [ ] Resolvés los ejercicios de cada especialización sin mirar la teoría (la regla de avance del mapa).
- [ ] Cada mini proyecto está en su subcarpeta de `proyecto/` y funciona.
- [ ] Marcaste cada especialización en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
