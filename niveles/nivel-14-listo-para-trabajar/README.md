# Nivel 14 – Listo para trabajar

Al terminar este nivel podés postularte a puestos junior: es el **hito de empleo** del mapa (unas 1090 h acumuladas).

- **Etapa:** [Nivel 14 – Listo para trabajar](../../README.md#nivel-14--listo-para-trabajar)
- **Requisitos:** Etapa 1, Etapa 2 (con CS61A) y la especialización Web del [nivel 13](../nivel-13-especializacion/). No depende de la Etapa 3, de las matemáticas ni de la IA.
- **Horas estimadas:** 340 (220 de temas y 120 del portfolio)

Django y FastAPI, uno por vez: empezá por Django si apuntás a backend web completo, o por FastAPI si apuntás a APIs, datos o IA. El otro llega con el segundo proyecto del portfolio.

## Ejercicios

- [ ] 1. Los ejemplos del tutorial de PostgreSQL sobre una base propia + 20 consultas escritas por vos sobre los datos del portfolio.
- [ ] 2. La capa de acceso a datos de la API del portfolio con psycopg 3, con tests.
- [ ] 3. Las 8 partes del tutorial de Django.
- [ ] 4. El tutorial completo de FastAPI.
- [ ] 5. Inspeccionar requests reales con las herramientas de desarrollo del navegador y con `curl`.
- [ ] 6. Contenerizar la API del portfolio con Docker Compose y PostgreSQL.
- [ ] 7. Revisar los dos proyectos web del portfolio contra el OWASP Top 10.
- [ ] 8. Los problemas de las sesiones de práctica de CS9 + los problem sets de 6.006 indicados en el mapa, cronometrados; simulacros de entrevista con otra persona.
- [ ] 9. Test de nivel de LearnEnglish; leer en inglés la documentación de todo el nivel.

## Portfolio (el proyecto de este nivel)

Unas 120 h. Cada proyecto conviene en su propio repositorio público, para mostrarlo a empleadores:

1. Una API con FastAPI, PostgreSQL y Docker, con tests.
2. Una aplicación web con Django y PostgreSQL, publicada online.
3. Un análisis de datos reales con pandas, documentado en un README.

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] Los tres proyectos del portfolio están publicados y enlazados desde `proyecto/README.md`.
- [ ] Los dos proyectos web pasaron tu revisión contra el OWASP Top 10.
- [ ] Hiciste al menos un simulacro de entrevista completo.
- [ ] Confirmaste nivel B2 de inglés con el test de LearnEnglish.
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones de los tutoriales, las consultas SQL y los problemas de entrevista.
- `proyecto/`: un `README.md` con los links a los tres repositorios del portfolio.
