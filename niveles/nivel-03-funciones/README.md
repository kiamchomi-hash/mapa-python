# Nivel 3 – Funciones

Al terminar este nivel podés dividir un programa en funciones con parámetros, valores de retorno y scope claros.

- **Etapa:** [Etapa 1 – Fundamentos](../../README.md#etapa-1--fundamentos-niveles-05)
- **Requisitos:** nivel 2. Desde este nivel empieza en paralelo el complemento de ciencias de la computación (Berkeley CS61A).
- **Horas estimadas:** 20

## Fuentes

- [MOOC de Helsinki 2026](https://programming-26.mooc.fi/) (partes 2–3)
- [Berkeley CS61A](https://cs61a.org/) (complemento en paralelo)

## Ejercicios

- [ ] 1. Ejercicios de las partes 2–3 del MOOC de Helsinki.
- [ ] 2. Labs y homework de CS61A sobre funciones.

## Mini proyecto

Reescribir el juego del nivel 2 con funciones que hagan una sola cosa cada una y una función `main()`.

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] El mini proyecto está en `proyecto/` y funciona.
- [ ] Podés explicar qué variables ve cada función de tu proyecto (scope).
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
