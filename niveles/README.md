Una carpeta por nivel del [mapa](../README.md), cada una con `teoria/`, `ejercicios/`, `proyecto/` y un README con fuentes, ejercicios, mini proyecto y criterios para avanzar. Para empezar: [nivel 0 – Preparación](nivel-00-preparacion/).

El orden de estudio no es el numérico: después del nivel 10 viene la especialización Web (nivel 13), después el nivel 14 y recién entonces los niveles 11 y 12. El detalle está en [Orden recomendado](../README.md#orden-recomendado).

Los tracks paralelos (terminal y Linux, matemáticas, sistemas, C y Rust, experto), la Etapa 4 y el Camino a IA no tienen carpeta propia: su trabajo va en `proyecto/` del nivel con el que se estudian, o en repositorios propios. Tu avance se marca en [TRACKER.md](../TRACKER.md).
