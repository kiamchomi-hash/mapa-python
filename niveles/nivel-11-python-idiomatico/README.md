# Nivel 11 – Python idiomático

Al terminar este nivel podés escribir Python idiomático con comprensiones, iteradores, generadores, decoradores y context managers.

- **Etapa:** [Etapa 3 – Python avanzado](../../README.md#etapa-3--python-avanzado-niveles-1113)
- **Requisitos:** el nivel 14 (hito de empleo). La Etapa 3 se estudia después del hito, mientras trabajás.
- **Horas estimadas:** 40

## Fuentes

- [Functional Programming HOWTO](https://docs.python.org/3/howto/functional.html)
- [Tutorial oficial: clases e iteradores](https://docs.python.org/es/3/tutorial/classes.html)

## Ejercicios

- [ ] 1. Labs y homework de CS61A sobre iteradores y generadores, rehechos sin mirar.
- [ ] 2. Ejercicios de generadores, decoradores y desempaquetado de [Exercism, track de Python](https://exercism.org/tracks/python).

## Mini proyecto

Un procesador de archivos de log grandes que los lee de forma perezosa con generadores, con un decorador propio que mide el tiempo y un context manager propio.

## Listo cuando

- [ ] Resolvés los ejercicios del nivel sin mirar la teoría (la regla de avance del mapa).
- [ ] El mini proyecto está en `proyecto/` y funciona.
- [ ] Reescribís un bucle con comprensiones o `itertools` sin perder legibilidad.
- [ ] Marcaste el nivel en el [tracker](../../TRACKER.md).

## Qué va en cada carpeta

- `teoria/`: tus apuntes, escritos con tus palabras como si le explicaras el tema a otra persona.
- `ejercicios/`: tus soluciones, un archivo por ejercicio.
- `proyecto/`: el mini proyecto del nivel.
