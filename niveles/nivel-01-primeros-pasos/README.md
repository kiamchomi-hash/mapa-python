# Nivel 1 – Primeros pasos

Al terminar este nivel podés escribir programas cortos que piden datos, hacen cálculos y muestran resultados con f-strings.

- **Etapa:** [Etapa 1 – Fundamentos](../../README.md#etapa-1--fundamentos-niveles-05)
- **Requisitos:** nivel 0.
- **Horas estimadas:** 15

## Fuentes

- [Harvard CS50P](https://cs50.harvard.edu/python/) (semanas 0–1)

## Ejercicios

- [ ] 1. [Problem sets de CS50P](https://cs50.harvard.edu/python/psets/): Problem Set 0.

## Mini proyecto

Un conversor de unidades (temperatura, distancia, moneda) que pide los valores con `input` y muestra los resultados con f-strings y dos decimales.
